PanelFox for Windows
====================

1. Unzip this folder anywhere (Desktop is fine).
2. Open the unzipped folder.
3. Double-click PanelFox.exe.

First launch: Windows may say "Windows protected your PC".
Click More info → Run anyway. That is normal for apps not sold in the Microsoft Store.

Your pages save on this PC. Use File → Export for PNG, PDF, CBZ,
or Webtoon Strip / Canvas (800px cuts for WEBTOON).
Projects save as .koma files.

Pin it: right-click PanelFox.exe → Pin to taskbar or Pin to Start.
