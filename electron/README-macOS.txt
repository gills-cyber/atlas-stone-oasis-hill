PanelFox for Mac
================

Apple Silicon (M1 / M2 / M3 / M4): open the "Apple Silicon" app.
Intel Mac: open the "Intel" app.

First launch
------------
macOS Gatekeeper flags apps that are not from the App Store.

1. Control-click (or right-click) PanelFox.
2. Choose Open.
3. Click Open in the dialog.

After that it launches like any other Mac app. Drag it to Applications if you want.

Your pages save on this Mac. Use File → Export for PNG, PDF, or CBZ.
Projects save as .koma files.
